Regras de Negócio e Engenharia

O sistema processa uma lista de medições de potência de sinal (em dBm) aplicando os seguintes critérios de validação e classificação:

  • Validação: Apenas valores entre -120 dBm e 0 dBm são aceites.
  • Normal: Sinal >= -85 dBm.
  • Alerta: Sinal ≥ -100 dBm e < -85 dBm.
  • Crítico: Sinal < -100 dBm.

O foco arquitetónico do sistema é a aplicação do Princípio de Responsabilidade Única (SRP), dividindo as tarefas em módulos independentes: validação, cálculos estatísticos, classificação e geração de relatório.

def is_valid_measurement(value: float, min_dbm=-120.0, max_dbm=0.0):

def classify_measurement(value: float) -> str:
    if value >= -85.0:
        return "Normal"
    if value >= -100.0:
